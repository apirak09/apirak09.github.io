# เที่ยวกับ P’dale · 7 November 2026

A Thai walking itinerary and countdown for a day with P’dale. Static HTML/CSS/ES modules; GitHub Pages at `/siam-walk2/`. No account, API key, build, or backend required.

The meeting is **7 November 2026, 08:35 Asia/Bangkok**. Countdown uses an explicit `+07:00` offset; it clamps at zero and changes its message at the meeting and after 17:40.

## Validation

`node --test core.test.mjs` checks fixed timezone countdown behavior and budget continuity through all stops. `node --check app.mjs` checks module syntax. Mobile/tablet/desktop map interactions and text sizes are verified in the browser. See `docs/design-notes.md` for the visual revision.

## Siam Walk 2 design

Redesign using [Taste Skill 2.5.0](https://github.com/Leonxlnx/taste-skill), source inspected 6 November 2026. Brand tokens generated by the skill: warm off-white, forest ink and terracotta. Local Figtree Latin fonts and IBM Plex Sans Thai; original venue photographs; unchanged itinerary, route geometry and countdown core. The skill’s unmodified motion layer handles primary-button hover and press.

This is an itinerary application, so the user's explicit content-preservation requirement takes priority over company marketing recipes (full-screen photo hero, sales sections, removal of photo captions and map restrictions). No marketing copy, made-up venues or replacement photographs were added.
