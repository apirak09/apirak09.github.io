# Jelly: Reborn

เกม RPG ผจญภัย 2D ใต้น้ำสำหรับ GitHub Pages เล่นผ่านเบราว์เซอร์โดยไม่ต้องติดตั้ง

**เล่น:** https://apirak09.github.io/jellyfish/

- โลกแบบด้านข้าง สำรวจได้ทุกทิศทาง: สวนปะการัง ป่าสาหร่าย ซากนครจม และร่องลึก
- วงจร 8 นาที: ตัวอ่อน 0–35 s → โพลิป 35–70 s → เอไฟรา 70–140 s → โตเต็มวัย 140–420 s → ชรา 420–480 s → กลับเป็นตัวอ่อน
- อวัยวะ 6 ชนิดที่เปลี่ยนทั้งรูปร่างและวิธีโจมตี: เข็มพิษ หนวดหนาม ถุงพิษ กระดิ่งเสียง ขนไฟฟ้า และเกล็ดเย็น
- ไข่มุกใช้เพิ่มชีวิต พลังโจมตี และการฟื้นพลังงาน การอัปเกรดติดตัวทุกชีวิต
- บอสหนึ่งตัว มี 3 รูปแบบโจมตี สัญญาณเตือนก่อนโจมตี และระยะคลุ้มคลั่งเมื่อชีวิตต่ำกว่าครึ่ง
- ความคืบหน้าบันทึกใน localStorage ของเบราว์เซอร์เครื่องนั้น ทุก 8 วินาทีและเมื่อทำกิจกรรมสำคัญ ไม่มีการซิงก์ข้ามอุปกรณ์
- เวลาเดินเฉพาะตอนเล่น เมนูและการสลับออกจากหน้าเว็บพักเกมให้อัตโนมัติ

## ควบคุม

| ปุ่ม | การกระทำ |
|---|---|
| WASD / ลูกศร | ว่ายน้ำ |
| คลิกค้าง / J | โจมตี เมาส์เล็งได้ J ช่วยเล็งศัตรูใกล้ตัว |
| Space / K | พุ่งหลบ ใช้ 22 พลังงาน |
| E | เก็บอวัยวะ / พักและตั้งจุดเกิดใหม่ / เริ่มบอส |
| 1–6 | เปลี่ยนอวัยวะ |
| I / M | ร่างกาย / แผนที่ |
| Escape | พัก / ปิดเมนู |

มือถือใช้จอยทางซ้ายและปุ่มโจมตี พุ่ง และสำรวจทางขวา แตะช่องอวัยวะเพื่อสลับอาวุธ รองรับทั้งแนวตั้งและแนวนอน

วงจรชีวิตและการกลายพันธุ์ดัดแปลงเพื่อการเล่น ไม่ใช่แบบจำลองชีววิทยา บอสเริ่มได้ตั้งแต่ระยะเอไฟรา โดยต้องมีอวัยวะอย่างน้อย 3 ชนิด การกลับเป็นตัวอ่อนเก็บอวัยวะ แผนที่ ไข่มุก จุดพัก และการอัปเกรดไว้ทั้งหมด

## พัฒนาในเครื่อง

เป็นไฟล์ static ล้วน ไม่มี dependency, backend, build step หรือการเรียก CDN

```bash
python3 -m http.server 8000
```

เปิด `http://localhost:8000/jellyfish/` ไฟล์ `game.js` แยกส่วนโลก วงจรชีวิต การต่อสู้ การวาดภาพ และ UI ด้วยฟังก์ชัน สำหรับการตรวจในเครื่องมี `window.jellyDebug` เฉพาะ hostname localhost / 127.0.0.1

## ตรวจสอบเวอร์ชันแรก

ผ่านการจำลอง engine: ทางน้ำเข้าถึงอวัยวะและจุดพักทุกจุด การว่ายและพุ่ง การเติบโตครบ 5 ระยะ การเกิดใหม่เมื่อครบ 8 นาทีและเมื่อเสียชีวิต ความเสียหายของอาวุธทั้ง 6 บอสทั้งสองระยะ รางวัลหลังชนะ การพักเวลา การบันทึกและโหลดต่อ รวมถึงการป้องกันการพุ่งทะลุกำแพง
