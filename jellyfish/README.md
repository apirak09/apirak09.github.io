# Jelly: Reborn · Biohybrid (Release 02)

เกม RPG ผจญภัย 2D ใต้น้ำบน GitHub Pages เล่นในเบราว์เซอร์โดยไม่ต้องติดตั้ง

**เล่น:** https://apirak09.github.io/jellyfish/

ปี 2147 คุณคือ J-01 แมงกะพรุนพร้อมอุปกรณ์ biohybrid ของสถานี PELAGIC สำรวจ 4 เขตทะเล ค้นหาโมดูล และกู้โดรนวิจัย NAUTILUS-01 ที่เปิดโหมดป้องกันผิดพลาด

## เปลี่ยนจากเวอร์ชันแรก

- วงจรชีวิตอิง Turritopsis dohrnii: โพลิปเกาะพื้นและแตกหน่อเมดูซา เพิ่มซีสต์ก่อนย้อนกลับเป็นโพลิป ใช้เมดูซาวัยอ่อนแทนเอไฟรา
- กระดิ่งโปร่งใส โครงสร้างภายใน อุปกรณ์ภายนอกร่าง ฐานเพาะเลี้ยง บันทึกวิจัย และบอสโดรนสำรวจ
- เซนเซอร์แสดงความลึก อุณหภูมิ กระแส และแรงดันประมาณจาก P = P₀ + ρgh ใช้ ρ = 1,025 kg/m³ กระแสน้ำมีผลต่อการว่าย
- บอสกับท่อกระแสอยู่บนแผนที่ตั้งแต่เริ่ม มีเส้นทางอ้อมภูมิประเทศ ลูกศรนำ และไฟหน้าประตู
- เริ่มบอสได้ด้วยโมดูลรวม 2 ชนิดในระยะเมดูซาวัยอ่อน มีทางลัดจากเขตแรก
- โซนาร์สแกนเปิดแผนที่ ใช้ 10 พลังงานและชาร์จ 6 วินาที
- ย้ายเซฟ v1 อัตโนมัติ เก็บโมดูล ไข่มุก อัปเกรด แผนที่ จุดพัก และผลชนะบอส

## ไปหาบอส

1. ตามเส้นสีส้มไปติดตั้งหนวดเสริมใยด้วย E ใกล้จุดเกิด
2. ตัวอ่อนเกาะพื้นเป็นโพลิปที่ 00:35 และแตกหน่อเมดูซาที่ 00:55
3. กด E ที่ท่อกระแสในสวนปะการังเพื่อไปฐานหน้า NAUTILUS
4. ตามไฟสีส้มทางขวา กด E ที่ประตู แล้วหลบแนวแดงและโจมตีช่วงโดรนพัก

เปิด B หรือแตะสัญญาณ NAUTILUS เพื่อดูขั้นตอน ขั้วไฟฟ้าใกล้ประตูเป็นตัวเลือกเพิ่มระยะโจมตี บอสมี 3 รูปแบบโจมตีและ 2 ระยะ โมดูลที่เหลือสำรวจต่อได้หลังชนะ

## ชีววิทยาและการดัดแปลง

T. dohrnii เป็นไฮโดรซัว เมดูซาย้อนพัฒนาผ่านซีสต์สู่โพลิปได้ โพลิปแตกหน่อเมดูซา จึงไม่ใช้เอไฟราของแมงกะพรุนอีกกลุ่ม การย้อนวัยไม่ได้ทำให้ฟื้นจากการถูกฆ่า

| เวลาในเกม | ระยะ | การเล่น |
|---|---|---|
| 0–35 s | ตัวอ่อน / planula | ว่ายและหาโมดูลแรก |
| 35–55 s | โพลิป / polyp | เกาะพื้น เก็บอาหารด้วยหนวด |
| 55–130 s | เมดูซาวัยอ่อน | สำรวจ ใช้ทางลัด เริ่มบอสได้ |
| 130–420 s | เมดูซาโตเต็มวัย | ร่างแข็งแกร่งที่สุด |
| 420–465 s | เครียดสะสม | อ่อนแรงก่อนย้อนพัฒนา |
| 465–480 s | ซีสต์ย้อนวัย | หยุดว่ายและโจมตี จัดโครงสร้างเนื้อเยื่อ |
| หลัง 480 s | โพลิปในรอบใหม่ | เกาะพื้น 20 วินาที แล้วแตกหน่อเมดูซา |

8 นาทีเป็นเวลาย่อเพื่อเกม ภาพตัวอย่างถูกขยาย ความทนแรงดัน โครงพยุง อาวุธ ท่อกระแส และตาข่ายเพาะเลี้ยงเป็นเทคโนโลยีสมมติ เมื่อเสียชีวิตฐานล่าสุดเปิดโพลิปสำรองและคงความคืบหน้า เป็นกลไก sci-fi การย้อนวัยตามเวลาจะกลับเป็นโพลิปบริเวณเดิม

อุณหภูมิและกระแสเป็นแบบจำลอง ไม่ใช่ข้อมูลสำรวจจริง เข็มพิษใช้ระยะใกล้ การยิงแคปซูล สร้างคลื่น ปล่อยไฟฟ้า และไฮโดรเจลมาจากอุปกรณ์ มีที่มา BIO / BIOHYBRID / ENGINEERED ในหน้าร่างกาย

- Pascual-Torner et al. (2022), *Comparative genomics of mortal and immortal cnidarians unveils novel keys behind rejuvenation*, PNAS. https://pmc.ncbi.nlm.nih.gov/articles/PMC9459311/

## พัฒนาและตรวจสอบ

ไฟล์ static ล้วน ไม่มี dependency, backend, build step หรือ CDN

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000/jellyfish/
node jellyfish/tests/engine.test.cjs
```

ชุดตรวจใช้ Node.js และ DOM/canvas จำลอง ตรวจวงจรชีวิต การเกาะพื้น ทางน้ำ โซนาร์ เส้นทางพร้อมระยะเผื่อร่างโตเต็มวัย ทางลัดและบอส 2 โมดูล การย้ายเซฟ v1 การต่อสู้ รางวัล การเกิดใหม่ การพักเวลา และการชนกำแพง window.jellyDebug มีเฉพาะ localhost / 127.0.0.1

รายละเอียดผลตรวจและภาพเบราว์เซอร์: [QA.md](QA.md)

การจำลองขนาดหน้าจอเป็นการตรวจ engine ต้องตรวจภาพและสัมผัสในเบราว์เซอร์เพิ่ม ไม่เท่ากับการทดสอบบนโทรศัพท์จริง
