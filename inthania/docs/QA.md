# INTHANIA — QC, UX และ UI

วันที่ตรวจ: 7 ตุลาคม 2026

## ผลที่ตรวจจริง

ผ่าน 46 รายการ: กติกาเกมและเซฟด้วย Node.js 12 รายการ การทำงานในเบราว์เซอร์ด้วย Playwright 32 รายการ และการแจ้งปัญหาเริ่มเกม 2 รายการ ไม่มี JavaScript error หรือคำขอไฟล์ที่ล้มเหลวตลอดเส้นทางเล่นปกติ รายละเอียดอยู่ใน [qa-results.json](qa-results.json) และ [boot-results.json](boot-results.json)

ใช้ Chromium 131 headless, WebGL 2 ผ่าน SwiftShader และโหลดเกมผ่าน HTTP จริง ไม่ได้ใช้ภาพจำลอง UI การเล่นเรื่องหลักใช้ตัวละครเริ่มต้น 2 คน การโจมตีและสกิลทำความเสียหายตามกติกาจริงจนบอสตาย ไม่ได้แก้ HP บอสให้จบการทดสอบ การเคลื่อนเวลาทีละเฟรมและการวางตัวละครที่จุดทดสอบใช้ช่องทาง `?qa=1` เพื่อให้ตรวจซ้ำได้ ส่วนเกราะและการฟื้น HP ใช้ข้อมูลตัวละครที่เตรียมเฉพาะการตรวจ แล้วคืนเซฟเดิม

## จุดที่พบและแก้ก่อนเผยแพร่

1. ฟอนต์ไทยแสดงเป็นช่องว่างในเครื่องที่ไม่มีฟอนต์ไทย: เก็บ Noto Sans Thai ในเกมและรอโหลดก่อนสร้างป้าย 3D
2. กดโจมตีสั้นแล้วกระสุนไม่ออก: ส่งคำสั่งโจมตีจาก keydown โดยตรง และยังรองรับกดค้าง
3. Esc เปิดแล้วปิดเมนูในเหตุการณ์เดียว: ป้องกัน native dialog cancel ในคีย์ที่จัดการเอง
4. ปุ่มเลือกทีมถูกวาดใหม่ระหว่างคลิก: อัปเดต DOM ทีมเมื่อข้อมูลเปลี่ยนเท่านั้น
5. การเดินเนินชันเลี่ยงเงื่อนไขปีนได้เมื่อเฟรมสั้น: ตรวจความชันจากระยะข้างหน้าแทนระยะเดินของเฟรม
6. ลานบอสสูงกว่าพื้นและวงเตือนถูกบัง: ปรับพื้นใต้ลานให้ราบ ใช้ groundAt สำหรับวงเตือนและตำแหน่งบอส
7. บอสเล็กมากทั้งที่กลไกต่อสู้ทำงาน: อัปเดต pose และ bone matrices ก่อนวัดขนาดโมเดล; แยกกลุ่มปรับขนาดออกจาก node ที่แอนิเมชันควบคุม; เพิ่มการตรวจความสูงจริงหลังแอนิเมชัน
8. แผนที่บนจอเตี้ยดันปุ่มวาร์ปพ้นหน้าต่าง: จำกัด canvas ตามความสูงหน้าจอและลดระยะห่างภายใน
9. ป้ายสกิลบนมือถือหักบรรทัดจนอ่านยาก: ใช้ชื่อการกระทำสั้นตามขนาดจอ
10. สีพื้นซีดเพราะส่งค่าสีใน color space ผิด: แปลงสี vertex จาก sRGB และใช้ output conversion ใน shader ท้องฟ้า
11. หน้าผิดพลาดบอกให้ลองใหม่แม้ระบบปิด WebGL: แยกสาเหตุกราฟิกจากการโหลดไฟล์ และหยุดปุ่ม retry ที่ไม่ช่วยแก้สาเหตุกราฟิก

## วิธีตรวจซ้ำ

จาก root repository:

```sh
node --test inthania/tests/state.test.js
INTHANIA_CHROME_PATH=/path/to/chrome node inthania/tests/browser.cjs
INTHANIA_CHROME_PATH=/path/to/chrome node inthania/tests/boot.cjs
```

การตรวจเบราว์เซอร์ต้องมี Node.js, Playwright และ Chromium ที่เปิด WebGL ได้ สคริปต์เปิด HTTP server ด้วย Python, เริ่มเซฟใหม่ใน browser context แยก, เขียนรายงานและภาพใน `docs/` แล้วปิด server เกมที่ใช้งานจริงไม่ต้องติดตั้ง dependency หรือ build

## ขอบเขตของผลตรวจ

ผลนี้ยืนยันการทำงานใน Chromium และ viewport จำลอง ไม่ใช่ผลทดสอบเครื่อง Android, iPhone, iPad หรือ Safari จริง ยังไม่ได้รับรอง FPS อายุแบตเตอรี่ ความร้อน GPU หรือการเล่นด้วยหลายสัมผัสพร้อมกันบนฮาร์ดแวร์จริง ตัวเลข draw calls/triangles ในรายงานเป็น snapshot ของฉากสุดท้าย ไม่ใช่ benchmark ประสิทธิภาพ

## การตรวจหลังเผยแพร่

GitHub Pages เผยแพร่สำเร็จ ตรวจดาวน์โหลด asset ทั้ง 27 ไฟล์จาก URL ออนไลน์แล้ว SHA-256 ตรงกับไฟล์ที่ใช้ทดสอบทุกไฟล์ ดู [deployment-check.json](deployment-check.json) เปิดหน้าออนไลน์และตรวจ URL จริงแล้ว เบราว์เซอร์ cloud ที่เปิดหน้านี้ปิด WebGL ส่วน Chromium สำหรับตรวจ WebGL โดยตรงมีข้อจำกัด certificate ของ proxy จึงไม่อ้างว่าเล่นจบจาก URL ออนไลน์ ผลเล่นจบข้างต้นมาจาก HTTP server ในสภาพแวดล้อมทดสอบที่ใช้ไฟล์เดียวกัน

เสียงเป็นเอฟเฟกต์สังเคราะห์สั้น ไม่มีดนตรีหรือพากย์ เกมเป็นต้นแบบเล่นคนเดียวขนาดย่อ มีโมเดลมนุษย์ 4 แบบสำหรับตัวละคร 6 คน ภูมิประเทศและอาคารเป็นงานตีความ ไม่มีเนื้อหาและปริมาณงานระดับ Genshin 1.0
