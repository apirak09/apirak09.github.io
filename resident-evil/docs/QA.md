## Automated checks

`npm run validate` covers unique IDs, bilingual fields, required sources, date precision, sorting, valid references, connections, spoiler tiers, biology cycles, independent Plaga/fungal origins, Rose's placement after Requiem and local assets. `npm run build` repeats validation and creates a static deployable folder.

Node syntax checking covers the buildless application. Relative asset paths and hash-addressed incidents support both domain-root and project-subdirectory deployments. There is no third-party JavaScript, backend, service worker cache or network API dependency.

Latest-release order is separated from in-world order. Biology avoids assigning unknown agents, parasites or fungi to unsupported virus parents. Character and source filtering respect knowledge boundaries; external source pages have a separate spoiler warning.
